What it is / 02

An auto-research agent for composite ML structures.

Non-additivity / 06

Composites can hurt. Airlock measures that.

좋은 것 둘을 합치면 나빠질 수 있습니다. 그것도 결과로 기록합니다.

superadditive harm · recorded
  • First-class result1 + 1 < 2 is a gate outcome, not an error. The pair gets a name and a reason.
  • In the real run8 harmful composites caught out of 37 evals. Each one closes a combination, not a factor.
  • Never retried silentlyHarms live in the ledger with both parents' scores, so the next round can't rediscover them.
